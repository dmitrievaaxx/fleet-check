# Автопарк на Go

Информационная система автотранспортного предприятия по контрактам кейса «Наведи порядок в
автопарке»: импорт шести CSV-выгрузок, справочники, нарушения и отчёты. Go 1.25, chi, PostgreSQL
через pgx; других модулей нет — ровно `go.mod` стартового шаблона.

## Запуск

    docker compose up --build

Сервис — на http://localhost:8000, проверка: http://localhost:8000/health. Данные лежат в
PostgreSQL на томе `db-data` и переживают `docker compose down` и повторный `up`.

Без Docker нужны Go 1.25 и PostgreSQL:

    export DATABASE_URL=postgresql://app:app@localhost:5432/app
    go run ./cmd/server

Настройки — переменные окружения: `PORT` (по умолчанию 8000) и `DATABASE_URL`.

## Тесты

    DATABASE_URL=postgresql://app:app@localhost:5432/tests go test ./...

Тесты API очищают таблицы базы из `DATABASE_URL` — давайте им отдельную базу. Без базы они
пропускаются, юнит-тесты импорта и правил идут всегда.

## Устройство

| пакет | что делает |
|---|---|
| `cmd/server` | подключение к базе, схема, запуск HTTP-сервера |
| `internal/api` | маршруты, разбор и проверка параметров, JSON и CSV ответов |
| `internal/importer` | описания шести наборов и проверки строки в порядке контракта; без базы |
| `internal/db` | схема, импорт одной транзакцией (COPY), списки, карточки, снимок для отчётов |
| `internal/domain` | снимок данных в памяти: сезон, пересечение интервалов, пробег на последнем ТО |
| `internal/rules` | девять типов нарушений |
| `internal/reports` | пять отчётов |
| `internal/jsonx` | JSON с порядком полей контракта |

Решения, которые стоит знать:

- Даты и времена хранятся строками фиксированной длины с побайтовой сортировкой (`COLLATE "C"`):
  строковое сравнение совпадает с хронологическим, порядок идентификаторов — по кодовым точкам.
- Импорт идёт по одному: уже сохранённые ключи читаются в начале, строки проверяются в памяти,
  принятые пишутся одной командой COPY в той же транзакции. Ошибка уровня файла ничего не пишет.
- Отчёты считаются по снимку базы в памяти; снимок строится заново после импорта, который
  что-то принял. Отчёт о нарушениях на 10 000 листов — миллисекунды.
- Любая ошибка — `{"error": {"code", "message", "details"}}`; параметры проверяются вручную,
  поэтому мусор в запросе даёт 400 `INVALID_PARAMETER`, а не 500.
